# 组织部

<div class="catalog-display-container">
  <Catalog base="/Organization/" />
</div># 发展党员的五个阶段及工作流程

## 一、申请入党阶段

### 1. 递交入党申请书
- **基本要求**：
  - 向工作/学习单位或居住地党组织提交书面申请
  - 申请人须年满18周岁
  - 必须本人亲笔书写并表达真实意愿

### 2. 党组织谈话
- **工作规范**：
  - 收到申请书后1个月内完成
  - 谈话内容：
    - 了解申请人基本情况
    - 做好谈话记录

## 二、确定入党积极分子阶段

### 1. 人选产生与确定
- **产生方式**：
  - 党员推荐
  - 群团组织推优
- **确定程序**：
  - 支部委员会研究决定（无支委会的由支部大会决定）

### 2. 后续工作流程
1. **上级备案**：
   - 上报材料包括：
     - 申请人基本情况
     - 推荐/推优情况
     - 支委会意见

2. **培养联系人**：
   - 指定1-2名正式党员担任
   - 工作职责：
     - 介绍党的基本知识
     - 定期开展培养教育

3. **培养考察**：
   - 培养方式：
     - 参加党课学习
     - 参与党内活动
   - 考察频率：每半年一次

## 三、确定发展对象阶段

### 1. 基本条件
- 经过1年以上培养教育
- 基本具备党员条件

### 2. 工作程序
1. **确定程序**：
   - 支委会听取：
     - 培养联系人意见
     - 党内外群众意见
     - 党小组意见

2. **备案要求**：
   - 报上级党委备案

3. **政治审查**：
   - 审查范围：
     - 发展对象本人
     - 直系亲属
   - 形成结论性材料

4. **集中培训**：
   - 时长要求：
     - ≥3天或≥24学时

5. **公示要求**：
   - 公示时段：
     - 支委会确定发展对象后
     - 支部大会表决前

## 四、接收预备党员阶段

### 1. 预审工作
- **审查内容**：
  - 培养教育情况
  - 政治审查结果
  - 培训公示情况

### 2. 关键流程
1. **填写志愿书**：
   - 在介绍人指导下如实填写

2. **支部大会**：
   - 会议流程：
     - 发展对象汇报
     - 介绍人介绍情况
     - 支委会报告审查情况
     - 无记名投票表决

3. **上级审批**：
   - 审批时限：
     - 一般3个月内
     - 最长不超过6个月
   - 审批前需专人谈话

## 五、预备党员转正阶段

### 1. 转正申请
- **时间要求**：
  - 预备期满前1个月提交书面申请

### 2. 工作流程
1. **意见征集**：
   - 党小组提出意见
   - 党支部征求党员群众意见

2. **支部大会**：
   - 表决要求与接收预备党员大会相同

3. **党委审批**：
   - 审批时限：3个月内
   - 结果通知：以批复文件形式

### 3. 档案管理
- **存档要求**：
  - 有人事档案的：存入人事档案
  - 无人事档案的：由所在党委建立党员档案
